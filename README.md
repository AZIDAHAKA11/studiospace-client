# StudioSpace - Peer-to-Peer Creative Workspace

StudioSpace is a premium marketplace platform where creators, filmmakers, and podcasters can discover, book, and list high-end production spaces.

## Tech Stack
- **Frontend:** Next.js (App Router), TypeScript, Tailwind CSS, Swiper.js
- **Backend:** Node.js, Express.js, MongoDB
- **Authentication:** JWT (HTTPOnly Cookies), bcrypt

## 5 Key Features
1. **Explore & Filter:** Browse multiple creative spaces with category filtering and a dynamic hero slider.
2. **Secure Booking System:** A real-time booking system with double-booking prevention.
3. **Host Dashboard:** Users can list their own studios with image URLs and full specs.
4. **Full CRUD & Modals:** Custom modals for updating, deleting studios, and cancelling bookings (no default alerts).
5. **Dark/Light Theme:** A fully responsive UI with a seamless dark/light mode toggle.
